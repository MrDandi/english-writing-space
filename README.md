# Write Level AI

Write Level AI is a modern web application for improving English writing through personal writing spaces, public sharing, peer comments, and AI-based writing level feedback.

The app is designed as a lightweight collaborative writing platform where users can create their own space, write stories or essays, read other people's writing, and check their estimated English writing level such as A1, A2, B1, B2, C1, or C2.

## Main Idea

Many English learners need a simple place to practise writing regularly. This project gives each user a personal writing space where they can write freely and improve over time.

Users can also explore public writings from others, compare writing styles, leave comments, and learn from different examples.

The app also supports AI writing evaluation. After writing a text, users can send it to an AI model to receive feedback about their writing level, grammar, vocabulary, clarity, and improvement suggestions.

## Features

- Create personal writing spaces
- Write stories, essays, notes, reflections, or practice paragraphs
- View public writings from other users
- Add comments and feedback
- AI-based writing level prediction
- Estimated CEFR level such as A1, A2, B1, B2, C1, or C2
- Modern note-taking style interface
- Smooth dark UI inspired by Obsidian
- Works as a static website using HTML, CSS, and JavaScript
- Can be hosted on GitHub Pages

## AI Writing Evaluation

The app can be connected to an AI API such as Google Gemini.

The AI can analyse the user's writing and return:

- Estimated English level
- Grammar feedback
- Vocabulary feedback
- Sentence structure feedback
- Clarity score
- Improvement suggestions
- Example corrected version

Example AI output:

```text
Estimated Level: B1

Strengths:
- Clear basic sentence structure
- Good idea development
- Understandable meaning

Needs Improvement:
- Some grammar mistakes
- Limited vocabulary variety
- Sentence flow can be improved

Suggestion:
Try using more linking words and more advanced vocabulary.
